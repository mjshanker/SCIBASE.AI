# Requirements Map

| Issue #16 requirement | Coverage in this module |
| --- | --- |
| Auto peer review reports | Produces disclosure-focused reviewer findings and revision tasks before the review packet is shown. |
| Statistical or methodological red flags | Flags sponsor/funder and related-party support that can bias interpretation of methods and claims. |
| Missing citations or scope misalignment | Flags primary-support citations with funder or affiliation overlap but no reviewer-visible context. |
| Claims vs. evidence alignment | Adds disclosure context to evidence and citation support so reviewers can assess related-party support. |
| Adaptive templates per domain | Sample projects cover clinical, environmental biology, and materials chemistry disclosure patterns. |
| Reproducibility checker context | Links disclosure confidence to registry, data-provider, and funding metadata needed for reproducibility review. |
| Real-time insights before release | Emits hold/revise/ready decisions and reviewer actions before the assistant packet is released. |

## Non-overlap

This slice is separate from broad assistant suites, protocol/evidence traces, statistics review, research-gap planning, rebuttal packs, ethics/data availability, citation-context reconciliation, reporting-guideline checks, benchmark leakage, figure/table checks, analysis-variable provenance, domain-template selection, grant-fit scoring, limitations disclosure, uncertainty calibration, supplement readiness, prompt safety, and study-power feasibility.
