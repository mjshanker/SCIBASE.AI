# Challenge Cancellation Accountability Guard

Self-contained Scientific Bounty System slice for sponsor cancellation and no-award decisions after solver work has started.

The guard reviews cancellation reason evidence, solver notices, appeal windows, escrow/refund state, partial-work compensation, per-solver review records, IP retention, and arbitration packet readiness. It uses synthetic sample data only and has no runtime dependencies.

## Commands

```bash
npm run check
npm test
npm run demo
```

Generated artifacts are written to `reports/`.
